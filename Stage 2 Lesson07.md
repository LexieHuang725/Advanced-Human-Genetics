# Lesson 7 - Sex Chromosome
## Sex chromosome features
* Skewed X inactivation (facilitated by
__Xist__) allows for relative tolerance
of X chromosome abnormalities
* Pseudoautosomal regions escape
inactivation
  - PAR1 contains skeletal genes (SHOX)
  - PAR2 affects ovarian function
* Other non-PAR genes also escape
X inactivation (__15__%)
* About __50__% of the Y chromosome is
genetically inert
* __SRY__, the testes determining gene, is
on Yp hear PAR1
* Azoospermia factor regions on Yq - fertility
* Loss of PAR2 seems to have no
phenotypic consequence

## Skewed X inactivation
* X inactivation is usually random. However, it is nonrandom for the following:
  1. Structurally abnormal X chromosomes (dels,
dups, isochromosomes)
  2. Translocations between X and autosomes
    - Balanced carriers: normal X is inactivated
    - Unbalanced offspring: der(X) is inactivated
